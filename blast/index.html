How do I export my contacts? (4 steps)
Easiest — on your Mac:
  1. Open the Contacts app
  2. Click any contact, press ⌘ + A (selects all)
  3. Menu: File → Export → Export vCard…
  4. Save it, then load that file up top ↑ (AirDrop it to your phone first if you want to do this on your phone)
Or from iCloud.com (works from phone):
  1. Go to iCloud.com → Contacts
  2. Tap the gear / "•••" → Select All
  3. Gear again → Export vCard → save to Files
  4. Load that file up top ↑
